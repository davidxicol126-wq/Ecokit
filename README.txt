# ECOKIT — Página web editable

Archivos:
- index.html = página principal
- imagenes/logo.png = logo proporcionado
- imagenes/ecokit-producto.png = segunda imagen proporcionada
- imagenes/hojas-cayendo.gif = animación de hojas del inicio

## Abrir
1. Descomprime el ZIP.
2. Abre index.html con Google Chrome.
3. Para editar, abre index.html en Visual Studio Code.
4. Guarda y presiona F5 en Chrome.

## Cambiar datos
En index.html puedes cambiar el precio, WhatsApp, correo, ubicación y redes sociales.
La galería quedó con una sola imagen: la segunda imagen proporcionada.
